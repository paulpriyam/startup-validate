# Contributing to India Startup Validator

We welcome contributions to make this skill more accurate and useful for Indian founders!

## Areas for Contribution

1. **Regulatory Updates:** India's regulatory landscape (RBI, SEBI, DPDP, etc.) changes fast. Help us keep `india-regulatory-screen.md` current.
2. **Market Data:** Add new benchmarks for ARPU, CAC, and conversion rates across different Indian sectors to `india-unit-economics.md`.
3. **Distribution Channels:** Share new ways to reach customers (e.g., new ONDC categories, emerging social platforms) in `india-distribution-channels.md`.
4. **Validation Experiments:** Contribute successful "low-cost" validation tests that work specifically in the Indian context to `validation-experiments.md`.
5. **Eval Cases:** Add new test cases to `evals/evals.json` to ensure the skill handles diverse startup ideas correctly.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your updates in the relevant files.
4. If adding a new feature, update `SKILL.md` if necessary.
5. Submit a Pull Request with a clear description of what you've changed and why it's important for the Indian market.

## Principles

- **India First:** All contributions must be specific to the Indian market.
- **Evidence-Based:** Avoid generic advice. Use [Data] or [Estimate] labels where possible.
- **Radical Honesty:** Keep the tone objective and critical. We are here to help founders avoid building things that shouldn't exist.
