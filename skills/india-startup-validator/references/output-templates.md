# Output Templates

Standardized formats for the Validator's deliverables.

## File Header
```markdown
# {Title}: {Project Name}
*Skill: india-startup-validator | Phase: {N} | Generated: {Date}*
*Confidence: High/Medium/Low*
```

## Red/Yellow Flags Section
```markdown
## 🚩 Red Flags (Critical)
- [Flag] - Rationale - [Assumption/Data]

## ⚠️ Yellow Flags (Watch items)
- [Flag] - Rationale - [Assumption/Data]
```

## Sources Section
```markdown
## 📚 Sources
1. [Source Name](URL) - Tier (1/2/3) - Date
2. [Source Name](URL) - Tier (1/2/3) - Date
```
