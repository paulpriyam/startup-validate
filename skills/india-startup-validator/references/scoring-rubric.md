# Scoring Rubric

The 10-dimension matrix for validating an Indian startup idea.

| Dimension | Score (1-10) | Rationale |
|---|---|---|
| **Problem Severity** | | How painful is this? (1 = minor annoyance, 10 = critical) |
| **Customer Clarity** | | Do we know EXACTLY who the target is in India? |
| **Willingness to Pay** | | Evidence that the target segment pays for such solutions. |
| **Market Size (India)** | | Is the SOM large enough to be a viable business? |
| **Competition** | | How crowded is the space (Direct + WhatsApp groups)? |
| **Regulatory Risk** | | Level of RBI/SEBI/GST/Legal complexity. |
| **Distribution** | | Do we have a clear, low-cost way to reach customers? |
| **Unit Economics** | | Can we make a profit per customer at India price points? |
| **Founder Advantage** | | Does the team have unique insights or access in India? |
| **Evidence Quality** | | Is this based on [Data] or just [Assumption]? |

## Verdicts
- **80 - 100 (Strong Proceed):** High confidence, clear path, manageable risks.
- **65 - 79 (Conditional Proceed):** Good idea, but 1-2 critical risks need testing immediately.
- **45 - 64 (Reassess/Pivot):** Fundamental flaws in economics, market, or distribution.
- **Below 45 (Stop):** Disqualifying signals (Regulatory blocker, no WTP, tiny market).
