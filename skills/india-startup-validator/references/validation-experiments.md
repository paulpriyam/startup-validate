# Validation Experiments

Actionable tests to prove an idea works in India.

## Experiment Types

### 1. Smoke Test (Demand)
- **Landing Page:** Simple site (Carrd/Wix) with a "Join Waitlist" button.
- **WhatsApp Ad:** Run a Meta ad that leads directly to a WhatsApp chat.
- **Search Intent:** Check volume for local keywords on Google Keyword Planner.

### 2. Concierge MVP (Value)
- **Manual Delivery:** Solve the problem for 5 people using manual tools (Sheets, Phone calls).
- **Consulting First:** Sell your expertise as a service before building the software.

### 3. Willingness to Pay (Economics)
- **Pre-Order:** Sell the product at a discount before it's built.
- **UPI Commitment:** Ask for a ₹99 "priority access" fee via UPI.
- **LOI (Letter of Intent):** For B2B, get a signed non-binding agreement to buy if features X, Y, Z are built.

## India-Specific Caveats
- **COD vs Prepaid:** If e-commerce, test if people will only buy via Cash on Delivery.
- **App vs Web:** Many Indian users avoid downloading new apps due to storage. Test a mobile-web or WhatsApp flow first.
- **Trust Seals:** Test if adding a GSTIN or DPIIT logo improves conversion.
